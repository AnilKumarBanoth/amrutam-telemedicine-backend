🛡️ Zero Double-Booking Architecture

Uses a two-phase concurrency guard: Phase 1 acquires an auto-expiring Redis distributed lock on the slot. Phase 2 performs an atomic PostgreSQL update verifying the version counter (version = version + 1). Concurrent requests are rejected with 409 Conflict.

🔒 AES-256-GCM Protected Health Information

Patient clinical notes, diagnoses, and medication prescriptions are encrypted at rest with AES-256-GCM and unique initialization vectors. Only assigned doctors and the patient can decrypt them; logs and raw database dumps reveal zero plain text.

⛓️ Tamper-Evident Hash Chained Audit Log

Every administrative and clinical action is cryptographically linked to its parent event using SHA-256 block hash chaining. Any modification or row deletion in the database breaks the mathematical chain and is flagged immediately.
